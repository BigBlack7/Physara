## 验证范围与停止条件

| 检查 | 需要区分的失败与最小证据 |
|---|---|
| V1 · 实例及灯的创作值 | 通过正式 Inspector 或同一域入口编辑两份同源实例之一的因子与纹理，清除／重放一个字段，用材质通道或基色证明真正消费及源继承，核对共享依赖 SHA。用一个不具备的 UV 集检查拒绝。用 Spot 的 cd、角度、可空 range 代表局部灯修改，并拒绝一次非法锥角。既有其他光型的单位和通道定义可引用匹配的 D07-T01/T03 证据。 |
| V2 · 资源资格、版本与 v1 往返 | 固定一项材质／灯修改，并通过两个入口核对主 View 的一档曝光。对参考场景环境执行一次设置／换源、移除和回放。检查有效请求各自推进 Scene 与 View 的版本，随后普通 Save As/Open 恢复接受值。用一个不可用源和一次可控的晚回候选检查 Pending、失败、冻结和旧身份。环境替换等待时核对请求、旧画面和真正接受帧的来源。 |
| V3 · 标样与线性 HDR | 从现有资源根打开固定 SHA 的参考场景，确认标准输入和主 View。用 D3 的正入射 4 lx、16 cd／2 m 与 16 cd／4 m，配合环境轴向样点和 +1 EV 比值，区分尺度、旋转及重复预曝光。保留配对的实际生产模式、栅格及 RGBA16F/D32 数据。已有上游参考可复用，意图和捕获需与实际输入匹配。 |
| V4 · 视口与真实窗口 | 复用 V3 同一输入和实际提交，核对 None/FXAA 的显示前 HDR／D32、斜边和平区，按 ViewOutput、实际合成及窗口编码对照方向及颜色。对齐样点按 D3 的 8 位误差口径检查。 |
| V5 · 成本事实与异步查询 | 同一参考场景比较首次上传和稳定重用，核对真实 GL 操作计数、资源口径和提交身份。用一轮安全 UI 或未出图的可达支路核对快照保留。支持的设备取一个真实 GPU 区间，验证等待、就绪、录制票据和安全退出；用受控延迟轮询覆盖容量分支，记录跳过及相关原生能力。 |

开发检查留在 `build/d07-t06/`。复用证明同一合同的已有独立预期或与当前输入相符的结果。达到所有实际改变的合同和 D07 出口证据后停止；仅在实际输入变化、失败或发现缺口时扩大检查。帧统计留存实际口径与作用域；同口径性能比较另外按 [12.2](../../../../Docs/Architecture.md#benchmark) 立论。 [验证技能](../../../../.agents/skills/physara-verification/SKILL.md)
