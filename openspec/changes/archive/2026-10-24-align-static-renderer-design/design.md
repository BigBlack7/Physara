# Design

## Context

动机和文件范围见 proposal.md。业务渲染尚未实现，本变更修改当前设计与计划；D00 归档保留其原始上下文。底层资料继续准确分析上游能力，不把 Physara 不采用的能力伪装为上游不存在。

## Goals / Non-Goals

**Goals:** 固定静态场景定位、可继续编辑的单文件场景合同、标准材质映射、静态时域效果、后端同步与失败边界；使开发计划按实际消费推进。

**Non-Goals:** 实现 C++/Shader/CMake，增加工具或测试框架，建设资产历史仓库，新增动态变形能力，缩减三路径或既定物理材质扩展。

## Decisions

1. **静态场景与相机重投影。** Scene 只保存静态实体/组件；编辑导致内容版本变化并保守失效 TAA/SSR。相机位姿独立更新，按 Filament 深度重建世界位置后重投影；历史深度、颜色、相机、曝光和 jitter 属于同一次成功提交。省去逐对象运动附件和骨骼前态，不保留无人消费的动画框架。所选模型实例实际使用 Skin/Morph 时明确拒绝；可达静态节点可使用节点初始变换，动画曲线不播放并报告。
2. **一个 JSON 与只读资产。** EditorSession 串行协调文件操作；Scene 拥有实体与实例覆盖，View 拥有 requested 设置，文件只保存快照。主 View 导航相机与设置进入文件，其它 View 为会话状态。Open 期间冻结文档编辑，候选校验通过才发布；Save 使用快照并允许后续编辑，成功只标记对应版本，Save As 的路径只在对应操作成功后更新。相比多文档并行操作，这更符合个人编辑器需求。
3. **资产重载。** 实例固定当前有效的不可变 CPU 版本，GPU 驻留从它派生；新版本先校验节点/Primitive/材质槽映射再激活。结构冲突由显式重载/重新绑定解决；无历史仓库时，不把未解决的源冲突普通保存为无法重新打开的引用。
4. **标准输入与 Filament 着色结构。** glTF 语义在导入和 MaterialInputs→PixelParams 边界明确转换，复用 Filament 的微表面、能量与照明组织；anisotropy、volume 空间、直接透射及 IBL 不用同名参数冒充等价。TAA/SSR 采用有固定来源的 Filament 数据流，SSR 明确深度命中、反射 mip、roughness/距离 LOD 与 IBL 回退。
5. **同源 RHI 与必要修补。** 保留固定 NVRHI 完整公共声明及语义，Common/Validation 按真实依赖引入，GL 按能力实现；Vulkan 原生依赖延后。修正 GL 读后写同步，提交失败不推进历史，设备失效不等待失败票据。未来 Vulkan 接入落实非 coherent flush/invalidate、复制前退出 rendering、Fatal 传播及并发 VCB 游标协议，不机械复制已确认缺陷。
6. **文档与顺序。** Reference 记录来源事实、限制和适用条件；Architecture 记录采纳方案与合同；Developments 安排首个消费者和验证；AGENTS 只规定通用开发行为。D01 先完成真实窗口；队列、arena 与 watcher 随真实消费者加入。当前结论直接替换过期叙述，不增加第二份审计报告。

## Risks / Trade-offs

- 编辑内容时重置历史会短暂重新收敛 → 换取不引入动态对象前态和 motion 管线，契合静态编辑目标。
- 单文档串行操作和 Open 期间冻结编辑限制并行操作 → 保持 UI 与取消可用，减少文件覆盖和迟到发布风险。
- SSR 属于屏幕空间近似，分组透明/折射仍有遮挡和排序限制 → 明确 confidence、IBL 回退及画质边界，不宣称完整光线传输。
- 静态源码核查不能证明 GPU 正确性 → 本轮仅验收设计、链接、阶段依赖和 OpenSpec；原生行为留在对应未完成工作包验证。

## Migration Plan

先更新规划与来源分析，再同步当前架构、计划、入口说明及 OpenSpec 上下文；最后检查残留承诺、锚点、计数和规格一致性。无需运行期迁移；不改写归档。未明确授权归档本变更，完成后保留待审核。
