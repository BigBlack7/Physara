# 图形合同

从具体工作包进入[架构索引](../../../Docs/Architecture.md)。核对本次改变的生产者、消费者、资源范围和数据单位，再选择对应条目。上游行为按 [Filament](../../../Docs/Reference/Filament_Rendering_Pipeline_Analysis.md) 或 [NVRHI](../../../Docs/Reference/NVRHI_RHI_Vulkan_Analysis.md) 的章节取证。

## 资源、命令与寿命

- CPU owner 与 GPU 完成是两条寿命线。提交保活、上传区段、描述符和原生删除按实际完成票据退休，并满足设备、线程和 context 前提。退出及设备失效覆盖受影响的在途工作。
- 区分资源/视图、布局/绑定、Pipeline 与命令动态状态。图节点声明实际读写、子资源、版本及进出状态。验证未初始化读、覆盖、RAW/WAR/WAW、非法 feedback 与环。非法图停止执行。
- 图负责依赖，后端按合同落实同步。根据生产者、后继访问和真实区域建立 barrier。原生状态缓存、资源访问跟踪与 CPU 脏标记分别表达各自的事实。互操作修改原生状态后更新或失效对应缓存。
- 命令的即时/记录/重放语义、可用队列及能力来自真实设备行为。不支持的路径明确拒绝。正常绘制避免全设备等待。池复用受格式、样本、usage、寿命和预算约束。

## Shader 与物理输出

- CPU/Shader 布局有一个权威定义，按变更用反射、生成或布局检查核对偏移、数组、矩阵与资源绑定。编译 key 含传递 include、选项、schema、工具版本，原生缓存还含设备/驱动身份。
- 热重载完整准备后切换兼容代，失败保留上一有效代和源映射诊断。变体只表达结构、布局或显著执行成本差异，连续参数走数据。
- 各路径共享材质模型、单位和着色公式。按架构核对坐标、深度、纹理原点、颜色空间、曝光及输出编码，在对应边界转换一次。注释说明算法来源、适用范围、近似与精度。导入扩展和可见降级如实报告。
- 验证依赖原生行为的同步、读回或销毁时，在实际 backend/context/device 上观察结果。比较着色或时域路径时固定输入、曝光、画质和容差，按目标选择 HDR 数值、参考图或序列。只修改纯 CPU 计算时，先用能区分错误结果的数值输入。
