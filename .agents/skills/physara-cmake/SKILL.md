# 构建与依赖

先从[构建说明](../../../Docs/Build.md)确认支持的工具、配置和实际入口。沿用根与模块的 CMakeLists.txt。

- 目标拥有自己的源文件、语言标准、警告和依赖。PUBLIC 只传播消费者编译/链接合同所需内容。第一方警告作为质量门槛，第三方诊断在对应 target 隔离。Debug/Release 与诊断开关独立。
- 在实际 target 旁用中文和英文标点说明用途、源码归属及重要依赖可见性。条件编译和非平凡生成步骤交代触发原因。沿用维护者的 VS Code 排版。
- 生成物进入 binary tree。声明真实输入、输出及传递依赖，支持首次构建和受影响输入的增量重建。生成工具不链接依赖其输出的目标。保留用户配置，避免机器绝对路径成为唯一路径。
- 第三方按项目选定的版本/commit 收录必要源码、许可与校验信息。沿用[依赖清单](../../../ThirdParty/README.md)，配置时不下载。NVRHI 快照仅供参考。机械移植记录上游路径、版本、许可和行为差异。
- 改到构建关系时，从实际消费者的 configure/build 入口验证。改了生成规则，再检查相应的干净或增量构建。只改说明文字时核对实际命令、目标和链接即可。
