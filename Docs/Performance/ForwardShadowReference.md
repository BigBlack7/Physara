## 固定画质判据

比较预曝光 RGBA16F、主 Reverse-Z D32 和对应阴影 D32 层。四档主深度逐字节一致，274,168 个地板样点与 `(25-8)/(25-0.1)` 的误差不超过 `2e-6`。Hard 512 与 PCF 512 的十一层 D32 逐字节一致。画质回放以固定几何 ROI 判定可见性，遮挡样点比 Off 的对应直接项低至少 `5e-4`，无遮挡样点的差不超过 `3e-4`。下表坐标均为 `z=0`，取以样点为中心的世界空间方形范围。 [画质与误差原始摘要](../../build/d09-t05/a/quality-summary.json)

## 实测分布和工作量

同一正式 Runtime/Renderer/Graph 启动路径，隐藏窗口，包含编辑器 UI。每档三轮交错，每轮接受一个配置帧后暖机六帧，再采 24 个接受暖帧。CPU 工作是 UI、场景准备、构图、编译及执行之和。GPU 时长按正常非阻塞轮询解析的原提交时间戳归属。四档各 72 个暖帧均有 Ready，四个冷帧及一个暖过滤切换也有 Ready。下表时间为毫秒。 [逐票据计时与尝试计数](../../build/d09-t05/a-correction-2/timing-reconciled.json)

| 档位 | CPU median / p95 | GPU median / p95 | 槽等待 median / p95 | 交换等待 median / p95 | 暖帧 D32 B |
|---|---:|---:|---:|---:|---:|
| Off | 1.707 / 2.396 | 2.095 / 5.096 | 0.035 / 11.949 | 0.084 / 0.257 | 0 |
| Hard 512 | 1.936 / 2.521 | 3.541 / 5.286 | 0.036 / 11.398 | 0.090 / 0.196 | 11,534,336 |
| PCF 512 | 1.921 / 2.618 | 3.712 / 5.487 | 0.038 / 11.707 | 0.084 / 0.240 | 11,534,336 |
| PCF 256 | 1.901 / 2.651 | 3.836 / 5.506 | 0.039 / 10.175 | 0.089 / 0.218 | 2,883,584 |

暖帧均为 13 次 Draw、6 笔共 40,454 B 的上传、零新增原生纹理及 Buffer。Off 为 51 次绑定，开启阴影为 56 次绑定。各开启档首次接受生成 11 层、28 个阴影批次，整图 41 次 Draw，原生纹理/Buffer 创建数依次为 `1/0`、`3/1`、`1/0`。票据 1384 从 Hard 512 切到 PCF 512 时复用 11 层、零重绘。 [冻结分布](../../build/d09-t05/a-correction-2/timing.csv) · [匹配的原始 GPU 查询](../../build/d09-t05/a-correction-2/gpu-resolutions.csv)

单独的原生压力回放确认 51 灯在同一图中争用，两路 View 冷帧各生产 16 层，暖帧各复用 16 层。整图实际 Draw 为 58 次和 16 次，设备图池有效峰值为 69,808,132 B。原生压力、画质及性能原始数据在 `build/d09-t05/` 的签收证据中。上面的场景、采样与判据可用于临时数据清理后的重建对照。 [最终压力记录](../../build/d09-t05/final/pressure-Release.log) · [验证回执](../../build/d09-t05/final/native-verify.json)
