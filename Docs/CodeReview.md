## 问题与整改

本轮尚未启动，尚无审查结论。B 开始后按下面的格式逐项记录，保持编号稳定；没有问题也必须填写覆盖、注释检查和验收结论。

以下仅为条目格式，不是已发现的问题。复制后填入实际内容；清空时保留此格式。

```markdown
### CR-001 [P1] 问题标题

- 位置：文件路径、符号和必要行号。
- 依据：对应规范/spec/设计合同。
- 问题：触发条件、实际行为和影响；附复现或代码依据。
- 整改与验证要求：期望结果及应执行的检查。
- [ ] A 已整改并自检
- A 修正与证据：修正位置、实际检查结果及记录引用。
- [ ] B 已复核通过
- B 复核与证据：实际确认的修正、回归及注释结果；不通过时说明原因。
```

优先级用于排序：P0 紧急阻断，P1 高风险，P2 一般缺陷/规范问题，P3 局部可读性问题。所有正式问题均须关闭或由 B 有依据地撤回；非阻塞建议单独注明。撤回保留理由，不勾选为已修复。
